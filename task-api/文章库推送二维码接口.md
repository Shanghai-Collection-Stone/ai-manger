# 文章库推送二维码接口

## 概述

本文档给外部程序接入文章库推送使用。核心流程是：

1. 管理端生成二维码内容。
2. 外部程序扫码得到 JSON：`{ "token": "...", "articleLibraryId": 1 }`。
3. 外部程序用该 JSON 调用文章库接口，获取库信息、领取下一篇文章或回写发布状态。

**基础路径**: `http://127.0.0.1:3011`

---

## 二维码内容格式

二维码内不是 URL，而是一个 JSON 字符串：

```json
{
  "token": "文章库推送token",
  "articleLibraryId": 1
}
```

| 字段 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `token` | string | 是 | 文章库二维码 token，由服务端生成并保存 |
| `articleLibraryId` | number | 是 | 文章库 ID |

> `token` 只绑定文章库，不是管理员登录 token，也不是任务 taskToken。

---

## 管理端：生成二维码内容

此接口给前端/管理后台使用。调用后如果文章库还没有二维码 token，服务端会自动生成并保存。

### 请求

```http
GET /api/article-library/:libraryId/push-qr
Authorization: Bearer <adminToken>
```

### 路径参数

| 参数 | 类型 | 描述 |
|------|------|------|
| `libraryId` | number | 文章库 ID |

### 响应

```json
{
  "pushUrl": null,
  "statusFilter": ["unpublished"],
  "qrPayload": {
    "token": "9f7c9d8a6b2e4f1c9a0b123456789abc",
    "articleLibraryId": 1
  },
  "qrContent": "{\"token\":\"9f7c9d8a6b2e4f1c9a0b123456789abc\",\"articleLibraryId\":1}"
}
```

### 响应字段说明

| 字段 | 类型 | 描述 |
|------|------|------|
| `pushUrl` | string \| null | 可选推送落地页地址 |
| `statusFilter` | string[] | 历史兼容字段；当前领取接口固定只取未发布文章 |
| `qrPayload` | object | 二维码 JSON 对象 |
| `qrContent` | string | 二维码实际编码内容，前端使用生产级二维码库生成二维码 |

---

## 扫码端：获取文章库信息

外部程序扫码后，可以先调用此接口确认文章库是否有效，并获取统计信息。

### 请求

```http
POST /task-api/article-library/detail
Content-Type: application/json

{
  "token": "9f7c9d8a6b2e4f1c9a0b123456789abc",
  "articleLibraryId": 1
}
```

也兼容 `libraryId` 字段：

```json
{
  "token": "9f7c9d8a6b2e4f1c9a0b123456789abc",
  "libraryId": 1
}
```

### 响应

```json
{
  "library": {
    "id": 1,
    "name": "种草文章库",
    "type": "小红书",
    "pushConfig": {
      "statusFilter": ["unpublished"],
      "pushUrl": "https://example.com/scan",
      "qrToken": "9f7c9d8a6b2e4f1c9a0b123456789abc"
    },
    "stats": {
      "total": 20,
      "publishedCount": 5,
      "unpublishedCount": 15,
      "occupiedCount": 2
    },
    "createdAt": "2026-04-29T00:00:00.000Z",
    "updatedAt": "2026-04-29T00:00:00.000Z"
  }
}
```

`stats.occupiedCount` 表示当前被占用的文章数：`publishStatus = "unpublished"` 且 `lockExpireAt` 晚于当前时间。租约释放或 15 分钟过期后，该数字会在下次刷新时下降。

---

## 扫码端：领取下一篇文章

此接口按 FIFO 顺序领取文章，但只会领取 `publishStatus = "unpublished"` 且没有未释放租约的文章。

已标记为 `published` 的文章表示已经发送，不会再被 `lease-next` 取到。即使请求体或文章库配置里包含 `statusFilter: ["published"]`，服务端也会忽略 `published`，不会把已发送文章重新放回领取池。

领取时服务端会给文章加 15 分钟租约，避免多个程序同时取到同一篇文章。

租约释放只有三种方式：

1. 等待 15 分钟自然过期。
2. 发布完成后调用“回写发布状态”接口，服务端会同时释放租约。
3. 放弃本次处理时调用“主动释放租约”接口。

在租约未释放前，同一篇文章不会被下一次 `lease-next` 取到。

### 请求

```http
POST /task-api/article-library/lease-next
Content-Type: application/json

{
  "token": "9f7c9d8a6b2e4f1c9a0b123456789abc",
  "articleLibraryId": 1
}
```

### 兼容字段：statusFilter

```json
{
  "token": "9f7c9d8a6b2e4f1c9a0b123456789abc",
  "articleLibraryId": 1,
  "statusFilter": ["unpublished"]
}
```

`statusFilter` 只作为旧调用方兼容字段保留。当前取文规则以文章状态为准：只取 `unpublished`，不取 `published`。

| 字段 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `token` | string | 是 | 二维码中的文章库 token |
| `articleLibraryId` | number | 是 | 二维码中的文章库 ID |
| `statusFilter` | string[] | 否 | 兼容字段；`published` 会被忽略，已发送文章不会被领取 |

### 响应：领取成功

```json
{
  "article": {
    "id": 101,
    "libraryId": 1,
    "title": "文章标题",
    "tags": ["标签1", "标签2"],
    "contentJson": {
      "markdown": "正文内容..."
    },
    "text": "纯文本正文",
    "imageUrls": [
      "/static/uploads/a.png"
    ],
    "imageIds": [12],
    "publishStatus": "unpublished",
    "source": "canvas",
    "sourceRef": {
      "canvasId": 5,
      "canvasArticleId": 2
    },
    "createdAt": "2026-04-29T00:00:00.000Z",
    "updatedAt": "2026-04-29T00:00:00.000Z",
    "lockExpireAt": "2026-04-29T00:15:00.000Z",
    "lastLeaseAt": "2026-04-29T00:00:00.000Z",
    "lastLeaseToken": "2d5b3b83-1111-4444-9999-2f0e9a123456"
  },
  "leaseToken": "2d5b3b83-1111-4444-9999-2f0e9a123456",
  "leaseExpireAt": "2026-04-29T00:15:00.000Z"
}
```

### 响应：暂无可领取文章

```json
{
  "article": null
}
```

### 响应字段说明

| 字段 | 类型 | 描述 |
|------|------|------|
| `article` | object \| null | 领取到的文章；没有可领取文章时为 `null` |
| `leaseToken` | string | 本次领取租约 token，领取成功时返回 |
| `leaseExpireAt` | string | 租约过期时间 |
| `article.id` | number | 文章 ID |
| `article.libraryId` | number | 所属文章库 ID |
| `article.title` | string | 标题 |
| `article.tags` | string[] | 标签 |
| `article.contentJson` | object | 结构化正文，常见字段为 `markdown` |
| `article.text` | string | 纯文本正文 |
| `article.imageUrls` | string[] | 图片路径 |
| `article.publishStatus` | string | 发布状态：`unpublished` / `published`；`published` 表示已发送，不会再被领取 |

---

## 扫码端：回写发布状态

发布完成后，外部程序可以直接用二维码里的文章库 token 回写文章状态，不需要 `todoId` 或 `taskToken`。

### 请求

```http
PATCH /task-api/article-library/articles/:articleId/status
Content-Type: application/json

{
  "token": "9f7c9d8a6b2e4f1c9a0b123456789abc",
  "articleLibraryId": 1,
  "status": "published",
  "leaseToken": "2d5b3b83-1111-4444-9999-2f0e9a123456"
}
```

| 字段 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `token` | string | 是 | 二维码中的文章库 token |
| `articleLibraryId` | number | 是 | 二维码中的文章库 ID；也兼容 `libraryId` |
| `status` | string | 是 | `unpublished` 或 `published` |
| `leaseToken` | string | 否 | 领取文章时返回的租约 token；传入后可防止过期任务覆盖新租约 |

### 响应

```json
{
  "ok": true,
  "article": {
    "id": 101,
    "publishStatus": "published",
    "publishedAt": "2026-04-29T00:10:00.000Z"
  }
}
```

> 推荐发布端传入 `leaseToken`。如果租约已过期并被其他程序重新领取，接口会返回 `{ "ok": false, "article": null }`，避免旧任务覆盖新租约。

---

## 扫码端：主动释放租约

如果外部程序领取文章后决定不处理，可以主动释放租约，让文章立即回到可领取队列，而不是等待 15 分钟自然过期。

### 请求

```http
POST /task-api/article-library/articles/:articleId/release
Content-Type: application/json

{
  "token": "9f7c9d8a6b2e4f1c9a0b123456789abc",
  "articleLibraryId": 1,
  "leaseToken": "2d5b3b83-1111-4444-9999-2f0e9a123456"
}
```

| 字段 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `token` | string | 是 | 二维码中的文章库 token |
| `articleLibraryId` | number | 是 | 二维码中的文章库 ID；也兼容 `libraryId` |
| `leaseToken` | string | 是 | 领取文章时返回的租约 token |

### 响应

```json
{
  "ok": true
}
```

---

## 兼容：任务机器人回写发布状态

如果调用方是任务机器人，并且拥有 `todoId` 与 `taskToken`，仍可使用旧接口回写文章状态。

```http
PATCH /task-api/:todoId/article-library/:libraryId/articles/:articleId/status
Authorization: Bearer <taskToken>
Content-Type: application/json

{
  "status": "published",
  "leaseToken": "2d5b3b83-1111-4444-9999-2f0e9a123456"
}
```

## 错误码

| 错误信息 | HTTP 状态码 | 描述 |
|---------|-------------|------|
| `AUTH_REQUIRED` | 401 | 管理端接口缺少管理员登录 token |
| `LIBRARY_NOT_FOUND` | 404 | 文章库不存在 |
| `ARTICLE_LIBRARY_ID_REQUIRED` | 400 | 请求体缺少有效的 `articleLibraryId` / `libraryId` |
| `ARTICLE_ID_REQUIRED` | 400 | 路径缺少有效的文章 ID |
| `ARTICLE_LIBRARY_TOKEN_REQUIRED` | 401 | 请求体缺少二维码 token |
| `INVALID_ARTICLE_LIBRARY_TOKEN` | 401 | 二维码 token 与文章库不匹配 |
| `INVALID_STATUS` | 400 | 状态值不合法 |
| `TASK_TOKEN_REQUIRED` | 401 | 任务机器人接口缺少 `Authorization` |
| `INVALID_TASK_TOKEN` | 401 | taskToken 无效 |
| `TASK_TOKEN_MISMATCH` | 401 | taskToken 与路径 todoId 不匹配 |
| `LIBRARY_NOT_BOUND_TO_TASK` | 401 | 当前任务未绑定该文章库 |
| `LEASE_TOKEN_REQUIRED` | 400 | 主动释放租约接口缺少 leaseToken |

## 接入示例

### JavaScript：扫码后领取文章

```js
const baseUrl = 'http://127.0.0.1:3011';
const qrPayload = JSON.parse(qrContentFromScanner);

const res = await fetch(`${baseUrl}/task-api/article-library/lease-next`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(qrPayload),
});

if (!res.ok) {
  throw new Error(`HTTP ${res.status}: ${await res.text()}`);
}

const data = await res.json();
if (!data.article) {
  console.log('暂无可领取文章');
} else {
  console.log('领取文章:', data.article.title);
  console.log('租约 token:', data.leaseToken);
}
```

### JavaScript：发布完成后标记已发布

```js
const articleId = data.article.id;

await fetch(`${baseUrl}/task-api/article-library/articles/${articleId}/status`, {
  method: 'PATCH',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    ...qrPayload,
    status: 'published',
    leaseToken: data.leaseToken,
  }),
});
```

### JavaScript：放弃处理并释放租约

```js
await fetch(`${baseUrl}/task-api/article-library/articles/${articleId}/release`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    ...qrPayload,
    leaseToken: data.leaseToken,
  }),
});
```

### JavaScript：管理端获取二维码内容

```js
const baseUrl = 'http://127.0.0.1:3011';
const adminToken = '管理员登录token';
const libraryId = 1;

const res = await fetch(`${baseUrl}/api/article-library/${libraryId}/push-qr`, {
  headers: { Authorization: `Bearer ${adminToken}` },
});

const data = await res.json();
console.log(data.qrContent);
```
