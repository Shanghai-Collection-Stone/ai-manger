# 任务专项接口 - 关键资源

## 概述

此接口提供对 `task-api` 所有资源的无差别访问，与 `task-api` 共用 `taskToken` 鉴权。区别在于：此接口会查询资源的归属关系，若资源未关联到当前任务则拒绝访问。

**鉴权方式**: 请求头 `Authorization: Bearer <taskToken>`

---

## 核心鉴权规则

| 规则 | 说明 |
|------|------|
| 每个接口必须携带 `Authorization: Bearer <taskToken>` | 无此 header 返回 401 |
| `taskToken` 与路径中的 `todoId` 必须完全匹配 | 不匹配返回 401 `TASK_TOKEN_MISMATCH` |
| 资源归属验证 | 查询资源是否关联到当前任务，未关联返回 401 或 `associated: false` |

---

## 统一响应格式

所有资源接口均使用统一的响应包装：

```json
{
  "resource": {
    "type": "资源类型",
    "id": "资源ID或null",
    "associated": true | false,
    "todoId": 10
  },
  "data": { ... },
  "message": "CANVAS_NOT_ASSOCIATED"
}
```

### resource 字段说明

| 字段 | 类型 | 描述 |
|------|------|------|
| `type` | string | 资源类型：`canvas` / `xhs_stats` / `items` / `todo` |
| `id` | number \| null | 资源 ID，未找到时为 null |
| `associated` | boolean | 资源是否关联到当前任务 |
| `todoId` | number | 关联的任务 ID（仅 list 接口返回） |

### 响应行为

| `associated` | HTTP 状态码 | 含义 |
|---------------|-------------|------|
| `true` | 200 | 资源存在且已关联，返回完整 `data` |
| `false` | 200 | 资源不存在或未关联，`data` 为 `null`，`message` 说明原因 |

---

## 通用错误码

| 错误信息 | HTTP 状态码 | 描述 |
|---------|-------------|------|
| `TASK_TOKEN_REQUIRED` | 401 | 未提供 Authorization header 或 Bearer token |
| `INVALID_TASK_TOKEN` | 401 | taskToken 无效或已过期 |
| `TASK_TOKEN_MISMATCH` | 401 | taskToken 与路径 todoId 不匹配 |
| `ITEM_NOT_BELONG_TO_TASK` | 401 | 执行节点不属于当前任务 |
| `STAT_NOT_BELONG_TO_TASK` | 401 | XHS 帖子数据不属于当前任务 |
| `CANVAS_NOT_ASSOCIATED` | 200 | 任务未关联此 Canvas |
| `CANVAS_NOT_FOUND` | 200 | Canvas 不存在 |
| `STAT_NOT_FOUND` | 200 | 帖子数据不存在 |

## 任务操作

### 获取任务详情

```
GET /task-api-resource/:todoId
Authorization: Bearer <taskToken>
```

### 更新任务字段

```
PATCH /task-api-resource/:todoId
Authorization: Bearer <taskToken>
Content-Type: application/json

{
  "status": "done",
  "taskResult": "# 执行结果\n这是内容"
}
```

### 删除任务

```
DELETE /task-api-resource/:todoId
Authorization: Bearer <taskToken>
```

## 执行节点操作

### 列出执行节点

```
GET /task-api-resource/:todoId/items
Authorization: Bearer <taskToken>
```

### 获取单个执行节点

```
GET /task-api-resource/:todoId/items/:itemId
Authorization: Bearer <taskToken>
```

### 新增执行节点

```
POST /task-api-resource/:todoId/items
Authorization: Bearer <taskToken>
Content-Type: application/json

{
  "title": "新步骤",
  "description": "步骤描述",
  "stage": "执行阶段"
}
```

### 更新执行节点

```
PATCH /task-api-resource/:todoId/items/:itemId
Authorization: Bearer <taskToken>
Content-Type: application/json

{
  "status": "done",
  "doneNote": "完成备注"
}
```

### 删除执行节点

```
DELETE /task-api-resource/:todoId/items/:itemId
Authorization: Bearer <taskToken>
```

## 统一资源读取

根据 `resourceId`（canvas ID 或 filename）精确获取关联资源。

### 获取关联资源

```
GET /task-api-resource/:todoId/resource/:resourceId
Authorization: Bearer <taskToken>
```

> `resourceId` 可以是 Canvas ID 或 task-api 目录下的文件名

**响应 - Canvas 类型：**
```json
{
  "resource": { "type": "canvas", "id": 1, "associated": true },
  "data": {
    "canvas": { "id": 1, "topic": "...", "status": "completed", ... },
    "articles": [...]
  }
}
```

**响应 - File 类型：**
```json
{
  "resource": { "type": "file", "id": "任务专项接口-XHS帖子数据收集.md", "associated": true },
  "data": { "content": "...", "filename": "任务专项接口-XHS帖子数据收集.md" }
}
```

**响应 - 未关联：**
```json
{
  "resource": { "type": "...", "id": "xxx", "associated": false },
  "data": null,
  "message": "RESOURCE_NOT_ASSOCIATED"
}
```

## Canvas 资源操作

### 获取 Canvas 文章列表

```
GET /task-api-resource/:todoId/canvas
Authorization: Bearer <taskToken>
```

**响应示例 - 已关联：**
```json
{
  "resource": {
    "type": "canvas",
    "id": 1,
    "associated": true
  },
  "data": {
    "canvas": {
      "id": 1,
      "topic": "画布主题",
      "status": "completed",
      "createdAt": "...",
      "updatedAt": "..."
    },
    "articles": [...]
  }
}
```

**响应示例 - 未关联：**
```json
{
  "resource": {
    "type": "canvas",
    "id": null,
    "associated": false
  },
  "data": null,
  "message": "CANVAS_NOT_ASSOCIATED"
}
```

> Canvas ID 从任务的 `associatedResources` 字段获取，格式为 `[{ type: 'canvas', resourceId: 123 }]`

## XHS 帖子数据操作

### 列出帖子数据

```
GET /task-api-resource/:todoId/xhs-stats
Authorization: Bearer <taskToken>
```

**响应：**
```json
{
  "resource": {
    "type": "xhs_stats",
    "id": null,
    "associated": true,
    "todoId": 10
  },
  "data": {
    "stats": [...]
  }
}
```

### 获取单条帖子数据

```
GET /task-api-resource/:todoId/xhs-stats/:statId
Authorization: Bearer <taskToken>
```

### 新增帖子数据

```
POST /task-api-resource/:todoId/xhs-stats
Authorization: Bearer <taskToken>
Content-Type: application/json

{
  "postTitle": "最好吃的火锅攻略",
  "tag": "美食",
  "likeCount": 1200
}
```

### 批量插入帖子数据（无论是否重复，每次都新增一条记录）

```
POST /task-api-resource/:todoId/xhs-stats/bulk
Authorization: Bearer <taskToken>
Content-Type: application/json

{
  "items": [
    { "postTitle": "帖子A", "likeCount": 100 },
    { "postTitle": "帖子B", "likeCount": 200 }
  ]
}
```

**响应**:
```json
{
  "resource": { "type": "xhs_stats", "id": null, "associated": true, "todoId": 10 },
  "data": { "ok": true, "upserted": 2 }
}
```

### 更新帖子数据

```
PATCH /task-api-resource/:todoId/xhs-stats/:statId
Authorization: Bearer <taskToken>
Content-Type: application/json

{
  "likeCount": 1500,
  "collectCount": 600
}
```

### 删除帖子数据

```
DELETE /task-api-resource/:todoId/xhs-stats/:statId
Authorization: Bearer <taskToken>
```
