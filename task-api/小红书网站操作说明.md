1. 小红书的检索使用 普通浏览器 ,不需要使用 ads 浏览器来采集,不用尝试 web_fetch 等类似工具,是必须使用模拟操作来获取实现的
2. 进行搜索的时候要点 筛选, 然后按任务要求设置排序,这样才能确保每一次数据列表得到的是一样的,筛选的弹窗只要设置好了,就可以点击其他的帖子了,筛选弹窗就会自动消失掉不需要管
3. 进入页面的时候尽可能使用模拟人工点击的方法,而不是直接跳链接,偏移一下位置 要更加无迹可寻一点
4. [!重要!] 小红书的收藏或点赞都在详情弹窗内,有时候会为空,一次获取不成功,其他帖子不要沿用逻辑来完成,其他帖子要重新尝试获取
5. 小红书的详情页通常是一个弹窗,可以关闭在采集就好了,不用每次都重置到搜索页的 这些会有很多没必要的步骤
6. 数据采集的可以尝试每次 Subagent | Crobjob 最多3个帖子的情况来进行收集,但可以线性往下采集达到采集要求
7. 小红书的帖子收集不要尝试采用跳到对应链接,极易触发风控,你应该模拟点击,打开弹窗来获取数据,而不是直接跳转链接,这样会更安全一些
8. 发文的时候要注意,发文需要填写tag标签,tag是需要模拟输入的,然后会出现弹窗,需要点击弹窗的第一个选项来选择tag,而不是直接输入完整的tag名称,否则会出现发文成功但是没有tag的情况,导致后续数据采集不到的情况
9. 发文成功后需要获取到帖子的链接,可以回到当前账号主页,然后点击新窗口打开第一个帖子来获取链接,必须新窗口打开,而且要等待窗口加载完毕后再获取链接,而不是直接在当前窗口打开,这样会更安全一些,也更不容易被风控发现
