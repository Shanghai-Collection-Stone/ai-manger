# Embedding Module

## 模块描述
该模块封装Google Generative AI的文本Embedding能力，提供单文本与批量向量化，并提供余弦相似度计算供向量检索回退策略使用。
文件路径: `src/modules/shared/embedding`

## 功能描述及关键词

### embedding.service.ts
提供文本向量化与余弦相似度计算服务。
- **关键词**: embedding, vector, gemini-embedding-001, google-genai, cosine, similarity, langchain, global, service

### embedding.module.ts
Embedding模块定义。
- **关键词**: module
