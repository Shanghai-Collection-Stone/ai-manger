# Canvas Module

## 模块描述
该模块基于MongoDB存储画布与文章列表，支持创建画布、批量追加文章、更新画布状态，以及为指定文章写入图片ID/URL与完成说明，用于批量生产与发布流程衔接。
文件路径: `src/modules/canvas`
