# Todo Module

## 模块描述
该模块基于MongoDB存储待办事项与其清单条目，包含AI考量、决策来源与执行计划字段，并提供REST接口供前端与工具使用。
文件路径: `src/modules/todo`

## 功能描述及关键词

### todo.controller.ts
Todo控制器。
- **关键词**: todo, tasks, todo-items, checklist, ai-plan, crud, mongo, controller

### todo.service.ts
Todo服务。
- **关键词**: service

### todo.module.ts
Todo模块定义。
- **关键词**: module

### todo.entity.ts
Todo实体。
- **关键词**: entity

### todo-item.entity.ts
清单实体。
- **关键词**: todo-item, entity
