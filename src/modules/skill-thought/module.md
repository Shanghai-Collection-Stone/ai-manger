# Skill-Thought Module

## 模块描述
该模块基于MongoDB存储思维链（thought），支持向量Embedding相似度检索与阈值合并，并向函数调用层导出工具以便Agent在完成任务后沉淀可复用知识。
文件路径: `src/modules/skill-thought`

## 功能描述及关键词

### skill-thought.service.ts
思维链服务。
- **关键词**: skill-thought, thought, memory, embedding, similarity, merge, retrieval, mongo, tools, service

### skill-thought.tools.ts
思维链工具。
- **关键词**: tools

### skill-thought.entity.ts
思维链实体。
- **关键词**: entity

### skill-thought.module.ts
思维链模块定义。
- **关键词**: module
