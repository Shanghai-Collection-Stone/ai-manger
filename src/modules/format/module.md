# Format Module

## 模块描述
提供去除 ```json 围栏与文本规范化的工具服务。
文件路径: `src/modules/format`

## 功能描述及关键词

### format.service.ts
格式化服务。
- **关键词**: format, code-fence, text, cleanup
- **函数**:
  - `stripCodeFences`: 去围栏/strip fences
  - `stripLeadingJsonLabel`: 前缀/strip json label
  - `normalizeJsonText`: 规范化/normalize json
