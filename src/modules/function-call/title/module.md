# Title Function-Call Module

## 模块描述
Title函数模块：根据首轮问答生成简洁标题，并写入上下文会话。
文件路径: `src/modules/function-call/title`

## 功能描述及关键词

### title.service.ts
标题生成服务。
- **关键词**: title, function-call, first turn, persist, service
- **函数**:
  - `getHandle.title_generate`: 生成标题/generate title
  - `ensureFirstTurnTitle`: 首轮自动/ensure first turn

### title.module.ts
标题生成模块定义。
- **关键词**: module
