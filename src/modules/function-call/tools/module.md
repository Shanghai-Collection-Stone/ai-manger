# Function-Call-Tools Module

## 模块描述
该模块负责聚合各Function-Call子模块与工具服务，统一对外导出工具提供者，并对不再使用的工具进行统一过滤，便于在Agent运行时以依赖注入方式加载。
文件路径: `src/modules/function-call/tools`
