# MCP-Function-Call Module

## 模块描述
该模块实现 MCP 资源工具与原生 MCP 工具加载能力：列出资源、读取资源、文件录入，并将 MCP 服务端暴露的工具提供给 Agent 使用，以访问或管理上下文资源。
文件路径: `src/modules/function-call/mcp`
